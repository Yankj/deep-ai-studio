```text
中美之外不是没人做AI：有的守住芯片关口，有的当机房房东，有的直接用开源，榜上才找不出第三国。
```

## 本期核心判断

1. 被喊出来的「第三名」，户口大多落在别处：投资第三、产量第三、机房第三，都不等于大模型第三。
2. 真下场从零练的，目前也只爬到半山腰。
3. 有的国家握着芯片供应链的关口，犯不着去这张榜上争名次。
4. 机房盖在本地，模型不一定是本地的。
5. 开源权重改了后来者的账：先用上，比追一个进不了前列的名次划算。
6. 根上卡住的是这个地方的互联网和云走到了哪一步，资本量级又把差距钉死了。
