# 抖音发布规范与风控复盘

本指南服务「深度长图文 / 口播短视频」在抖音的发布。写作上仍按 [写作规范](./writing-playbook.md) 追求锋利与深度；发布前必须再做一轮平台风控检查。规则来自两次复盘：第 001 期初版被判定为「不适宜公开」（措辞类雷区，见第 5 节）；第 003 期长文被判「涉嫌色情导流风险行为」（见第 8 节和 [该期复盘](../issues/2026-11-14-ai-testing-e2e/platform-risk-retrospective.md)）。

交付抖音内容前，主笔先自己跑完 [第 8 节的自检](#8-发布前平台风险自检)，附一行自检结论再交，不等发出去再补救。

## 1. 标题备选规范

一次至少准备 2–3 个标题，发布时按风险从低到高挑选。

好标题应同时满足：

- 有明确对象和事件，不靠虚空概念撑场
- 有判断或张力，但不写成恐吓、煽动或荐股
- 尽量避开高风险类别中的点名、指控和金融口号

示例（取自第 001 期，可作后续参照）：

1. **执掌英伟达33年，两周仓促退场：算力牌桌正在重洗**（稳妥推荐）
2. **当「AI 基础设施总闸门」突然换帅，芯片与大模型格局会怎么变？**
3. **33年创始人突然告别，英伟达之后谁来接住算力新周期？**

若标题里已经出现公司名和人事变动，正文就不要再用更刺激的冲突词去「加码」。

## 2. 作品描述：60 字以内

抖音作品描述按 **60 字以内** 作为红线（不含标签）。建议结构：

1. 一句现象（时间跨度 + 关键动作）
2. 一句判断（表象 vs 真正被改写的东西）
3. 一句收束（时代变化，但不喊「接盘」「上车」）
4. 标签控制在 **3 个**，优先放行业与主题，不堆人物八卦标签

节奏上短句断开，便于扫读，不要写成一段密不透风的长句。

第 001 期合规示例：

```text
执掌33年，两周仓促告别。
个人风波只是表象，真正被改写的是全球算力供给、开源生态与芯片竞争格局。
单核时代落幕，新棋局开启。

#英伟达 #AI算力 #芯片行业
```

压缩字数时，先删情绪副词和重复判断，再删可从正文推断的解释；不要为了压字数把结论改成金融口号。

## 3. 封面图规范

完整规范见 [封面与海报设计规范](./cover-design.md)，抖音场景记住这几条：

- 比例 **3:4 竖版**，首图就是封面。
- **冲击力和完整可读优先**：主题词占上半部 40% 以上，超粗、高对比；副标题放进高对比色块；所有字完整落在画框内，按 216×288 缩略图检查能否读全。
- 早期第 001 期用过「无字底图、到平台再叠字」的做法，已被上面的海报式封面取代：字要和画面一起设计，不靠后贴。
- **画面合规**：不出现支付页、金额、订单号、交易 ID、二维码、手机号、网址、社交账号、聊天截图、像私密页面的界面；人物不暴露、无暧昧姿态和擦边构图。
- **规避强象征性公共建筑剪影与高风险主题叠加。** 单独一张图不一定过不了审，但和特定主题文案一起出现时，会抬高综合风险分。若封面被单独拦截，换成纯科技场景，不靠加字硬闯。

## 4. 情绪配乐：先定情绪，再选曲子

不要先找「大气」或「燃」，先确认文章情绪。第 001 期从权谋张力收束到「退场、落幕」后，配乐也一并改道。

适合「退场、落幕」的参照曲目：

| 曲目 | 为什么合适 |
| :--- | :--- |
| Max Richter《On the Nature of Daylight》 | 冷峻克制，几乎没有冲击点，适合长图文里的时间流逝感 |
| Hans Zimmer《S.T.A.Y.》 | 管风琴与钢琴缓慢退行，带一点科技史诗的余韵 |
| Ludovico Einaudi《Experience》 | 钢琴起手、弦乐铺开，适合帝国筑起又骤然谢幕的苍凉 |
| Hans Zimmer《Time》纯钢琴版 | 抽掉交响的宏大，只留回响，适合公众号或更静的阅读场 |

发布建议：

- 图文 / 公众号：优先《On the Nature of Daylight》或《S.T.A.Y.》，不抢文字
- 口播 / 短视频：若需要轻微卡点，可考虑同一情绪下节奏稍清晰的钢琴版，仍避免鼓点和歌词抢旁白

版权以各平台曲库可引用范围为准，发表前再确认一次授权状态。

## 5. 风控复盘：三类高危雷区

「不适宜公开」往往不是单一句子的问题，而是几类高风险信号叠在同一篇里。发布前按下面三类排查。对比只保留**方法论和替换原则**，不回写未脱敏原文。

### 雷区 A：涉政、地缘与未证实指控

典型风险方向：点名具体政治人物或党派、把未证实的涉外安全指控写实、用对抗性的封锁或点名话术讨论跨境规则。

替换原则：把焦点从「谁在政治上发力」转到「规则环境与合规成本会怎么变」。

| 高风险写法方向 | 更稳妥的替换 |
| :--- | :--- |
| 点名政治人物、党派、具体法案博弈 | 写「跨区贸易规则趋严」「行业沟通枢纽换人后，原有平衡被打破」 |
| 把未证实的安全指控当事实陈述 | 写「外部合规争议」「供应链合规质疑」，并标明调查方已公开的边界 |
| 用对抗性的封锁、卡位话术描述政策 | 写「跨境采购审核、云端远程调用的合规门槛抬高」 |

### 雷区 B：隐私、桃色与粗俗表达

典型风险方向：详细铺陈私人关系、点名非必要的当事人、使用粗俗自述或猎奇细节。平台容易把这类内容和「不实传闻 / 侵犯隐私 / 低俗」归到一起，尤其再叠加上一条未证实指控时更危险。

替换原则：只保留对治理和商业判断必要的信息，私人细节能不写就不写。

| 高风险写法方向 | 更稳妥的替换 |
| :--- | :--- |
| 渲染私人关系细节、点名非必要当事人 | 写「私人交集」「涉及内部高管的关系」 |
| 用猎奇或粗俗措辞传达情绪 | 写「致歉」「忏悔表态」「个人失误与家庭代价」 |
| 把私人事件写成丑闻连续剧 | 按时间线写清每阶段的**治理功能**，不写情节 dramatization |

### 雷区 C：证券引导与市场情绪口号

典型风险方向：强调暴跌幅度、市值关口、以及「谁来接盘」「某公司是最大受益者」这类容易被理解为荐股或煽动交易的句子。短描述里尤其危险，因为平台会把作品描述当作独立审核对象。

替换原则：可以写波动和格局变化，不要写交易动作，也不要把推演写成买卖建议。

| 高风险写法方向 | 更稳妥的替换 |
| :--- | :--- |
| 突出单日跌幅、市值关口、抄底或接盘 | 写「出现剧烈波动」「全球市值前列的位置受到冲击」 |
| 「某同行是最大受益者」的结论口吻 | 写「同行有望承接分流需求」「客户将预算拆出一部分做备份」 |
| 「看谁接盘」「缩表 / 高杠杆」等金融黑话 | 写「新棋局开启」「对外部生态的激进投入可能收紧」 |

专栏里为了观点力度可以使用更锋利的小标题；同步发抖音时，标题、描述和口播稿都要再降一档。

## 6. 脱敏改写原则

1. **先保判断，再换措辞。** 合规不是把文章写平。产业结构、供需松动、生态托底收缩这些推演可以留，只替换触发审核的表达。
2. **事实与传闻分级。** 官方公告、公司自查口径、媒体报道、外界质疑，必须分层；未证实事项只写到「存在争议」，不下定论。
3. **少点名、少定罪、少给交易信号。** 尤其不要在 60 字描述里使用这类词。
4. **发布位置也影响过审。** 同类内容建议优先选择「科技 / 商业观察」，而不是强金融口播类目；先发图文测试，再决定是否上口播。
5. **公开仓库只留合规版。** 复盘记录方法与替换表，不存高风险原稿。

- [ ] 标题是否避开了三类雷区，且仍有判断？
- [ ] 描述是否在 60 字内，标签是否不超过 3 个？
- [ ] 正文是否删除了未证实指控、不必要的私人细节和交易导向词？
- [ ] 封面是否为 3:4，缩略图下主标题能否读全，是否避免了高象征性建筑与敏感主题叠加？
- [ ] 是否已跑完第 8 节的平台风险自检，并附上自检结论？
- [ ] 配乐情绪是否与「文章语气」一致，版权是否可用？
- [ ] 类目选择是否偏科技 / 商业观察？

## 8. 发布前平台风险自检

**必做，交付前自己查完再给。** 2026-11-15，第 003 期的 AI 测试长文被判「涉嫌色情导流风险行为」，账号新作品减少推荐、限制被搜索各 30 天。一篇纯技术文也会踩中，说明「内容本身没问题」不能代替检查。复盘见 [第 003 期平台风控复盘](../issues/2026-11-14-ai-testing-e2e/platform-risk-retrospective.md)。

### 文字

- [ ] 正文、标题、摘要、封面字、图中英文全部扫过一遍
- [ ] 没有色情、低俗的谐音和歧义词，包括中英混排、拆字、缩写可能被误读的组合
- [ ] 没有「私信」「加我」「链接」「领取」「福利」这类导流词
- [ ] 没有微信号、站外链接、联系方式

### 画面

- [ ] 封面和配图里没有支付页、金额、订单号、交易 ID
- [ ] 没有二维码、手机号、网址、社交账号、聊天截图
- [ ] 没有像私密页面的界面
- [ ] 人物没有暴露、暧昧姿态或擦边构图
- [ ] 没有网图、带水印截图、搬运素材

### AI 生成内容

- [ ] 发布时勾选「内容由 AI 生成」声明
- [ ] 图里没有伪造的真实 App 界面

### 发布节奏

- [ ] 同一账号短时间内没有密集发风格相近的长文
- [ ] 被限流后不删了重发

### 交付格式

自检结论一行写清：查了哪些、改了哪些、还剩什么风险。有疑点先改再交。

## 9. 抖音长文创作方法

抖音长文在推荐流里先被当成「一条会自动滚动的视频」来竞争，点开后才比阅读质量。所以分两步：先让人点开，再让人读完、愿意互动。下面的做法来自 2025-09 至 2026 年的公开报道和创作者经验；没有官方来源的流量数字一律不采用。

- **平台规则**：长文最多 8000 字、30 张图，可配背景音乐；电脑端在创作者中心发布。目前没有按阅读量现金分成的公开规则，变现靠商单、带货、知识付费和精选计划。
- **首图**：首图就是封面。好首图有三种：直接放结果、写读者会搜的那句话、用反常识对比。
- **标题**：前半句放搜索关键词，后半句放钩子，例如「前端 leader 落地 AI 测试｜难的不是点那一下」。摘要和开头两三行直接给结论或冲突，不写寒暄。
- **配乐**：一定配，选无歌词、节奏轻的。
- **选题**：优先第一人称的真实经历和个人判断，比如真实项目复盘、带团队转 AI 的决策。资讯整理类会被平台的 AI 资讯摘要挤掉；工具清单更适合发普通图文。
- **篇幅与版式**：日常 1500–3000 字。手机上每段三到五行，每段配判断式小标题，隔几段插一张图。
- **结尾**：放一份读者愿意截图收藏的清单或总结，再问一个具体问题，问法每篇都换，不说「欢迎评论」。
- **首评**：发布后十分钟内由作者自己写第一条评论，补一条文中没写的关键信息，并逐条回复早期评论。
- **账号策略**：用普通图文低成本测选题，用长文建立信任，再用出镜视频放大转化。内容围绕「前端出身、做 AI Agent 落地」这个垂直定位，好题目做成系列。投放只投自然流量已经起来的文章，留意平台官方活动和精选计划。
- **雷区**：网图、带水印截图、搬运内容会被判非原创；文中留微信号、二维码或站外链接会被限流；不写成软文广告；不把一张长图切成多张发，也不把全文塞进文案区。
