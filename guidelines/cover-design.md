# 封面与海报设计规范

封面是主题海报。它要让人 1 秒读出这篇的判断，再用字、构图、光色和物件把这句话托住。成稿时封面和 60 字以内描述同轮交付，不事后补。

本规范从第 001–004 期的封面迭代里沉淀而来，后两期反复返工的地方都写进来了。相关文档：[写作规范](./writing-playbook.md)、[抖音发布规范](./douyin-publishing-guide.md)。

## 1. 字要被设计，图文互相响应

封面设计的第一件事是字。字形本身要有意图、有设计感；图和文是同一件被设计过的东西。

- **不要拿默认字体放大，贴在画完的图上。** 那是贴标签。检验办法：把字换成一款普通粗黑体，画面仍然「站得住」，说明字还没被设计过。
- **每个字体决定都要说得出理由**：为什么是这个粗细、这种切法、这种字距、这样与画面碰撞或嵌入。
- **字要进入画面**：被画面裁入、刻进材质、随破面错位、随透视嵌入、占据画面裂缝的领土。手段为这篇的判断服务，上一张用过的形式（裂口、左右岸、某种分区）不能当公式复用。
- **主标题是主题判断或反差**，要瞬间读懂。数字只有本身就是主题时才上主标题。艺术字必须可读，不堆效果，不把正文整段搬上图。
- **描述和标题分工。** 60 字描述可以承担价格、场景等钩子；不要把描述再念一遍当标题，反过来也一样。

## 2. 构图为字和判断服务

- 左右或多区对比时，各侧的判断写在对应区域里，让字落在它所属的材质或空间上，不做成居中堆叠、与画面无关的大标题。第 004 期把各国标签放进各自的地层，就是这个做法。
- 隐喻要一眼可读，人物、物件、光色都为判断服务。
- 标识与标题是一组锁定：默认 logo 在上、文字在下，落在同一块视觉领土里。

## 3. 抖音封面：冲击力和完整可读优先

抖音封面是在信息流里被刷过去的，第一眼要撞人。

- 主题词占画面上半部 40% 以上，超粗、高对比，有材质和光（金属、霓虹、扫描光）。一层主标题、一层副标题就够，最多再加一个小钩子。
- 主题词就是主标题（例如「AI Testing」），副标题回答怎么做或难在哪（例如「如何实现端到端」），放进高对比色块（黄底黑字之类），保证缩略图上也能读。
- 画面讲一条看得懂的故事线，比如代码 → 手机 → 闸门，一眼看出「端到端」。含蓄、雕刻、细小的字，在抖音上等于没有。
- 所有字完整落在画框内，四周留安全边距。
- **画面里不出现支付页、金额、订单号、交易 ID、二维码、手机号、网址、社交账号、聊天截图和像私密页面的界面。** 用手机界面表达业务流程时，换成中性的流程图示或空白卡片。

## 4. 官方标识

- 出现具体产品或品牌时，用未改动的官方 logo 和官方名称，从官方品牌包或产品页取。
- 先核对标对不对：公司标和产品标是两回事，别误用姊妹产品或母公司的标。
- 不改色、不变形、不拼成新标，不暗示官方背书。

## 5. 制作流程

1. **先定字的设计意图**：这组字在画面里要做什么（占领土、被裁切、刻进材质、随透视、与物件共用一条断面），再让画面为这个意图造型。不先画氛围底图再贴字。
2. **出图前先看同类**：在社交平台、开源社区和官方品牌页上对照同类海报与标识规范，学完再画。开源社区里有专门的电影感大字标题提示方法（例如 GitHub 上 WoYun520/gif-factory 的 cinematic-title-lettering）：先写清哪个字最大、怎么断行、哪一笔有特点、放在画面哪里，再让模型一次画出整组字。
3. **生成与核字**：模型直接生成英文大字和短中文效果最好，字和画天然一体。生成后逐字放大核对，错字、缺笔、乱码，以及画面里的伪代码和小字乱码，都要局部修补或重生成。较长的中文用真实字体排字，后期处理是为了实现设计好的字图关系（蒙版、透视、材质刻字、光学校正），不是把默认字体摆正。
4. **缩略图检查**：按 216×288 的缩略图看一遍，主标题能一眼读全，字仍像长在画面里；任何一个字被裁、被压或看不清就重做。
5. **画面合规检查**：按 [抖音发布前平台风险自检](./douyin-publishing-guide.md#8-发布前平台风险自检) 的画面一项逐条过。
6. **先给作者看构图和字级**，获批后再替换已发布的封面。

## 6. 规格

- 短视频、竖版图文默认 3:4；博客或横版头图可用 16:9 或 2:1。
- 归档进本仓库的封面单张不超过 3MB，命名 `cover-3x4.jpg`。
- 只归档已获批、已上线且通过画面合规检查的封面。
- 避开无必要的时政地标、可识别的名人肖像、商标侵权和满屏英文堆砌。
